# Fourthform editorial system

Fourthform uses warm ivory, muted ochre, charcoal and the four-corner frame motif. Agency navigation and wordmarks share the same family across marketing, preview onboarding and the connected portal. Customer website typography remains independent.

## Typography

- Schibsted Grotesk: navigation, body text, controls and the main interface.
- Archivo: agency identity and the condensed hero expression.
- Instrument Serif: editorial emphasis and the italic hero expression.

The headline presents one accessible sentence. Its three native animation tracks share a fixed slot, wait for local fonts, pause offscreen and in hidden tabs, and become static for a reduced-motion preference. The existing eight-card orbit and staircase navigation are preserved. There is no animation-start button.

All font files are locally served. The shared font directory includes the applicable open font licences.

## Reference direction

- [Sincro](https://sincro.es/en/us/): open grotesk typography, thin rules and asymmetric information placement.
- [The Romans](https://www.wearetheromans.com/): condensed headline scale and clear hierarchy.
- [Agrumea](https://www.agrumeafarm.it/en): restrained serif accents and a warm spatial composition.

Reference sites informed proportion and composition. Their proprietary typefaces were not downloaded.

## Portal surfaces

The sidebar, top bar and work stage use flat surfaces. Active navigation uses a restrained solid fill; primary actions use charcoal. Editing surfaces have no perpetual decorative animation. The mobile More menu keeps an opaque surface above its workspace.

Public names are Custom website, One-page website, Included tools and Advanced tools. Internal package IDs, prices, payment stages and saved draft keys remain compatible.
