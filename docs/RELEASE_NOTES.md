# Fourthform release notes

2 October 2026, Australia/Brisbane.

This release improves purchasing clarity, authentication recovery, phone navigation, review feedback, draft recovery, publication, scheduled content and portfolio exploration. All product copy is checked for em dashes. The 20 fictional studio concepts now explain their visitor goal, design choice and intended journey without invented customer outcomes.

Marketing distinguishes an example brief from real onboarding, includes a clear scope discussion, a conditional enquiry route and a practice introduction. Publishing shows changed content, and managed website approval pins the reviewed revision under the database lock. States are edited as drafts and activated with an explicit versioned receipt.

The agency setup now has structured pages, fields, theme controls and a validated advanced import. Customer image fields support meaningful descriptions, decorative images and editable focal points. Reports explain daily visitor estimates and action clicks; the Inbox has filters, search and per-message action feedback. Domains and launch disclose their exact destination, DNS purpose and verification freshness.

Local production builds, type checks, marketing structure/copy checks, portal preview/backend/environment suites pass. Local browser installation is unavailable in this sandbox; browser and real Supabase evidence is produced by the root GitHub workflow for the release candidate. The workflow must finish before promotion to main.

Production deployment is not claimed by this document. The connected Vercel read tools identify the intended projects, but their advertised create-deployment tool is unavailable. No production credentials were found in this authorized checkout. Provider acceptance and public URL verification remain separate from source acceptance.

Actual service terms, delivery commitments, hosting/support policy, ownership and founder identity must be supplied by the agency. The site explicitly requires those details to be agreed before paid work and does not invent them. Online agency enquiries require a real recipient and configured sending identity. Stripe settlement, Google login, notifications, scanning and custom domains require configured providers and staging acceptance. Screen-reader evaluation and a production performance benchmark remain human/live acceptance tasks.
