Preview data and transactions always remain local. Preview card editing and consent controls illustrate external provider interfaces, not an in-house payment editor or a universal consent platform. The connected Inbox is a real post-launch feature; sample test enquiries demonstrate its handoff without sending.

A focused space has its own draft. Opening the complete example starts a separate draft and provides a return link. Embedded previews remove duplicated outer navigation; feature controls remain in the marketing page. Optional task suggestions never force a tour.
